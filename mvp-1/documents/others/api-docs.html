Documentação da Pulse Mais WebAPI

Referência completa dos endpoints expostos pela aplicação. Todos os erros seguem o formato { "error": "mensagem" }.

Use a navegação à esquerda para saltar entre módulos.

GET POST PUT DELETE

Health /health

GET /health

Verifica se o servidor e o banco estão operacionais.

Respostas

StatusDescriçãoBody
200 Servidor e banco operacionais. 
{ "status": "ok", "db": "connected", "project": "Pulse Mais G01" }
503 Banco indisponível. 
{ "status": "error", "db": "disconnected" }

Alunos /alunos

Importação /importacao

POST /importacao/alunos
RF / RNRF006, RN06, RN08

Importa alunos a partir de arquivo CSV ou XLSX.

Headers

Content-Type: multipart/form-data

Body

Form field "arquivo" — arquivo .csv ou .xlsx. Colunas obrigatórias: nome, email, senha, cpf.

Respostas

StatusDescriçãoBody
200 Todos os registros importados sem conflito. 
{ "importados": integer }
207 Importação parcial — alguns CPFs já existiam. 
{ "importados": integer, "conflitos": [{ "linha": integer, "cpf": string, "motivo": string }] }
400 Formato inválido ou colunas ausentes (RN08). sem corpo
