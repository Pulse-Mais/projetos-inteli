Documentação da API REST

Nexus WebAPI

Documentação completa dos endpoints da plataforma Nexus, desenvolvida para a Pulse Mais. Todos os endpoints seguem arquitetura REST, retornam JSON e estão vinculados aos Requisitos Funcionais (RF) e Regras de Negócio (RN) definidos no WAD.

Formato: JSON
Autenticação: Session-based
Banco: PostgreSQL
Runtime: Node.js
Base URL http://localhost:3000/api/v1

Autenticação · RF004 NEW
RF004
Autenticação e Controle de Sessão
Login com e-mail e senha, gerenciamento de sessão via cookie e verificação de perfil ativo. Perfis: aluno, coordenador, gestor, psicólogo (RN001).
POST /auth/login Autenticar usuário
Descrição
Valida credenciais e inicia sessão. Ao autenticar com sucesso, o servidor define o cookie session_id e retorna o perfil do usuário com seu papel (role). Usuários com status = false são bloqueados (RN001).
Headers
Content-Type: application/json
Body 
{
  "email": "carlos@email.com",
  "senha": "Senha@123"
}
CampoTipoObrigatórioDescrição
emailstringSimE-mail cadastrado (primário)
senhastringSimSenha da conta
Resposta 200 
{
  "message": "Login realizado com sucesso.",
  "usuario": {
    "id": 101,
    "nome": "Carlos Sales",
    "email": "carlos@email.com",
    "role": "aluno"  // "aluno" | "coordenador" | "gestor" | "psicologo"
  }
}
// Set-Cookie: session_id=<token>; HttpOnly; Path=/
Status codes
200Autenticado — cookie de sessão definido
400Campos obrigatórios ausentes ou formato inválido
401Credenciais inválidas
403Usuário inativo (RN001)
500Erro interno

GET /gestor/:rm/alunos/filtros Filtrar alunos (gestor)
Descrição
Permite ao gestor ou coordenador editar dados cadastrais completos de um aluno (nome, e-mail, telefone, turma, gênero, data de nascimento). Campos de jornada e prontuário psicológico não são editáveis por este endpoint (RN011). Diferente do PATCH /aluno, este endpoint não é acessível pelo próprio aluno.
Headers
Content-Type: application/json
Cookie: session_id=<token>
Path params
ParamTipoDescrição
idintegerRA do aluno
Body 
{
  "nome": "Carlos Sales Atualizado",        // opcional
  "email_primario": "carlos.novo@email.com",  // opcional
  "email_secundario": "carlos2@email.com",    // opcional
  "tel_primario": "11999990001",            // opcional
  "tel_secundario": "11988880001",           // opcional
  "genero": "Masculino",                    // opcional
  "data_nasc": "2003-05-10",               // opcional
  "id_turma": 2                             // opcional
}

Pelo menos um campo deve ser enviado. Campos omitidos não são alterados.

Resposta 200 
{ "message": "Dados do aluno atualizados com sucesso." }

  "ex_aluno": true    // opcional — marca como egresso
}
CampoTipoObrigatórioDescrição
statusbooleanSimNovo status do aluno
ex_alunobooleanNãoClassifica como ex-aluno/egresso
Resposta 200
