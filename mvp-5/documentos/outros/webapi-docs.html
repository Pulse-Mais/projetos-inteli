Documentação da WebAPI

Documentação técnica dos endpoints REST da plataforma Pulse Mais, coerente com a Matriz RF ⇒ RN ⇒ Endpoint (seção 3.1.4), os diagramas de sequência UML (seção 3.2.4), o modelo físico do banco de dados (seção 3.6.3) e a RTM (seção 3.9). Atualizada na Sprint 04 para refletir o estado real do código validado por 333 testes automatizados.

Todos os endpoints retornam JSON, com exceção de GET /export (text/csv). Erros seguem o formato { "error": "mensagem curta" }. O campo presente (frequencia_aula, participacao_evento, sessao_mentoria) utiliza BOOLEAN nativo desde a Sprint 04; os campos encerrado e ingressou permanecem SMALLINT com valores 1/0. Operações de escrita sobre o Jovem exigem id_usuario para rastreabilidade (422 quando ausente).
